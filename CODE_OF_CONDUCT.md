# Community code of conduct

Multi-Account MCP for Gmail & Drive is a security-sensitive project. Clear disagreement and careful scrutiny are welcome; hostility and careless disclosure are not.

## Expected conduct

- Be respectful, specific, and patient.
- Critique ideas and code without attacking people.
- Assume good faith while still asking for evidence.
- Protect other people's privacy and use synthetic data in public examples.
- Disclose conflicts of interest and correct mistakes plainly.
- Help keep discussions focused on the project's local, read-only trust boundary.

## Unacceptable conduct

Harassment, discrimination, threats, sexualized attention, doxxing, impersonation, sustained disruption, or publishing another person's private data or credentials is not accepted in project spaces.

## Enforcement

Maintainers may edit or remove content, close discussions, issue a warning, or temporarily or permanently restrict participation. Decisions should be proportionate, documented privately when appropriate, and protect reporters from retaliation.

For a private conduct report, contact the repository owner through a private channel available from the [maintainer's GitHub profile](https://github.com/djehuty94). Include links and a factual description, but do not redistribute sensitive material. Immediate threats or platform abuse should also be reported to GitHub.

This code applies to repository discussions, issues, pull requests, reviews, and project-affiliated public spaces.
